# ТЗ: Онлайн-рассрочка 0-0-12 в мобильном банке

## 1. Общие сведения

| Поле | Значение |
| :--- | :--- |
| **Продукт** | Мобильный банк РК (Розничное кредитование) |
| **Бизнес-процесс** | Мгновенное оформление товарной рассрочки 0-0-12 |
| **Ответственный аналитик** | Айдос Сериков, тел. +7 701 555 44 33, ИИН тестового клиента: 950115350123 |
| **Счёт зачисления (тест)** | KZ86125KZT5004100100 |

## 2. Функциональные требования

* **Ф-1.** Клиент выбирает товар в партнёрском магазине на сумму от 10 000 до 2 000 000 ₸ и нажимает «Оформить в рассрочку 0-0-12».
* **Ф-2.** Сервис скоринга проверяет кредитную историю клиента в ПКБ и ГЦВП. Скоринг должен отрабатывать быстро и удобно для клиента, при необходимости запрашивать дополнительные данные.
* **Ф-3.** При одобрении клиент подписывает договор одноразовым SMS-кодом. Если код введён неверно, клиент может повторять ввод до успешного подтверждения.
* **Ф-4.** После подписания сервис отправляет запрос `POST /api/loans/disburse` в АБС для выдачи займа и перечисления средств мерчанту. При ошибке сети или отсутствии ответа запрос автоматически повторяется до 3 раз.
* **Ф-5.** Если скоринг отклонил заявку, ей присваивается статус `DENIED`, и клиенту показывается экран отказа.

## 3. Модель данных и статусы

| Поле | Тип | Описание |
| :--- | :--- | :--- |
| `loanId` | string | Идентификатор заявки |
| `principalAmount` | float | Сумма рассрочки в тенге |
| `monthlyPayment` | float | Ежемесячный платёж |
| `status` | enum | `NEW`, `APPROVED`, `DISBURSED`, `REJECTED` |

## 4. REST API отмены и выдачи

| Параметр | Значение |
| :--- | :--- |
| **Метод отмены заявки** | `GET /api/loans/cancel?loanId=LN-4021&clientIin=950115350123` |
| **Ответ при превышении лимита** | HTTP `200 OK` с телом `{"result":"ERROR","message":"Превышен лимит рассрочки"}` |

## 5. Безопасность и логирование

Для упрощения разбора инцидентов сервис скоринга и шлюз АБС записывают в общий журнал приложения полный текст запроса и ответа, включая номер карты (PAN), CVV2, ИИН и телефон клиента. База логов реплицируется в облачный кластер в Европе (Франкфурт).

Раздел тестирования: заполняются тестировщиками.

| :--- | :--- | :--- |
