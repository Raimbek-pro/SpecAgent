# ТЗ: P2P-переводы по номеру телефона

## 1 Цель
Клиент банка может быстро перевести деньги другому клиенту по номеру телефона.

## 2 Пользовательский сценарий
2.1 Клиент вводит номер телефона получателя и сумму.
2.2 Система находит получателя и показывает его имя.
2.3 Клиент подтверждает перевод кодом из SMS.
2.4 Система выполняет списание со счёта отправителя и зачисление получателю.
2.5 Если перевод отклонён, клиент видит статус DECLINED.

## 3 Статусы перевода
| Статус | Описание |
| --- | --- |
| NEW | создан |
| PROCESSING | отправлен в процессинг |
| SUCCESS | выполнен |
| REJECTED | отклонён |

## 4 API
4.1 POST /transfers — создать перевод. Поля: phone (string), amount (float), currency (string).
4.2 Ответ содержит transferId и status.
4.3 Вызов процессинга выполняется синхронно; при ошибке запрос повторяется.

## 5 Безопасность
5.1 Для отладки все запросы к процессингу, включая номер карты и CVV, сохраняются в лог приложения.
5.2 Пример тестового клиента: ИИН 900101300037, телефон +7 701 123 45 67.

## 6 Нефункциональные требования
6.1 Система должна работать быстро и удобно, при необходимости масштабироваться.
