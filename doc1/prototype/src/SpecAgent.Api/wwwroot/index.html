1. Политика автоисправления (Patches)

Нажмите i рядом с любым параметром, чтобы открыть подсказку.

С какого уровня критичности агент переписывает раздел. При «Minor» исправляются абсолютно все проблемные разделы документа.
Сколько максимум проблемных разделов переписать за один запуск. Защищает от лишнего расхода токенов на огромных документах.
Сколько попыток даётся агенту-писателю исправить критический раздел, если верификатор нашёл несостыковку с соседними разделами.
Сколько разделов исправляется одновременно в параллельных потоках. Выше — быстрее аудит, но зависит от лимитов API (для Kimi Tier 1 оптимально 6).
Если выключено (по умолчанию) — в скачиваемый fixed.pdf / .docx / .md попадает только чистый текст ТЗ, а Gherkin остаётся под стрелкой разбора.

4. Модель LLM и глубина рассуждений

Провайдер: OpenAiCompatible

Базовая LLM для агентов-критиков, арбитра и автоисправления. kimi-k3 быстрее и дешевле, kimi-k3.1-pro — глубже для сложных архитектурных ТЗ.
Глубина внутреннего рассуждения модели: low даёт быстрый ответ за 15–30 сек, high/max — дольше, но тщательнее на запутанных спецификациях.
